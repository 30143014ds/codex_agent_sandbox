# Core beliefs and perfectionism

Start from a specific recurring thought the user wants to understand; do not infer a deep belief solely from a score or a phrase. Read [methods.md](references/methods.md) for downward-arrow inquiry, book belief domains and experiments. For the full chapter-14 practice menu, read [perfectionism-menu.md](references/perfectionism-menu.md) when perfectionism is the focus. Optional DAS administration belongs to `$cbt-assessment`.

Ask what the thought would mean if true, following only meanings the user actually supplies. Offer a formulation as tentative and invite correction. Stop inquiry when the pattern is clear, it becomes repetitive, the user wants to stop, or distress rises without useful learning. Do not dig for a predetermined “core wound.”

Examine the rule's protective value, current costs, evidence and exceptions. Develop a flexible alternative that retains an important value. Test it with a small voluntary action whose outcome can inform either hypothesis. An experiment is for learning, not proving the agent right.

With perfectionism, agree on the task's real quality/safety requirements. Vary an unnecessary standard, time limit or checking habit in a low-stakes setting; do not deliberately introduce errors into safety-critical, legal, financial or care work. Review effort, checking, completion, anxiety, enjoyment and actual consequences.

Save the formulation with its status (hypothesis/agreed), prediction, action and observations. Change it when the evidence changes. A high standard alone is not a disorder.

Sources: Burns chapters 10–14; CCI perfectionism materials supplement behavior/rule experiments and broadening bases of self-evaluation.
