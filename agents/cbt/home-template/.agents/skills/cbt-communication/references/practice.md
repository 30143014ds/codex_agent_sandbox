# Communication practice

## Responding to criticism

- Ask what specific behavior the person means and listen for a concrete concern.
- Acknowledge a true or understandable part if there is one. This “disarming” move is optional, not agreement with insults or unsafe demands.
- Admit a genuine mistake and offer a proportionate correction when appropriate.
- State disagreement with an inaccurate conclusion calmly and specifically.
- Negotiate the next observable step when both parties are willing; leave or pause an unproductive/unsafe exchange when needed.

## Clear requests and refusals

Describe an observable behavior, its impact, and a clear request. Express feelings as one's experience rather than using a feeling phrase to disguise an accusation. Ask for the other perspective if that is useful and safe. Appreciate real cooperation without flattering or promising control over the result.

For saying no, use a brief clear refusal, an optional reason, and an alternative only if genuinely available. Repetition can maintain a boundary without increasingly elaborate justification. Plan what the user will do if the boundary is ignored; a boundary describes their action, not a threat to control someone else.

## Rehearsal loop

Choose a real phrase the user expects to hear. Practice one reply; ask what felt natural or difficult; try a revision. Increase realism only by agreement. Reflect any assumptions the exercise reveals and test them outside the role-play through safe observation.

Optional later TEAM/Five Secrets adaptation: seek an element of truth, reflect thought/feeling, inquire, state one's own feelings clearly, express sincere respect. These are tools to choose from, not obligations to placate every aggressor.
