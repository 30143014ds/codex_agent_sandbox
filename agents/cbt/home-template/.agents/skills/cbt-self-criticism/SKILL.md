# Self-criticism, shame and guilt

Identify the precise self-judgment and the event behind it. Separate behavior, consequences, responsibility and a global claim about worth. Explore the function of criticism: protection, improvement, belonging or moral responsibility may be real values, even when the method is costly.

Choose one method from [methods.md](references/methods.md). Use `$cbt-thought-record` for a full record, `$cbt-core-beliefs` for recurring conditional worth, or `$cbt-communication` for guilt-inducing demands and boundaries.

Examine actual responsibility fairly. If the user caused harm, acknowledge the behavior and work toward proportionate repair rather than blanket reassurance or self-punishment. If blame is misplaced, test causal assumptions without declaring the user responsible for another person's decisions. Compassion and accountability can coexist.

Invite a fairer response, an appropriate action, and emotion/belief reratings if useful. Ask whether the new response feels accurate. Save what the user actually endorses, keeping tentative interpretations separate.

Do not promise that a philosophical statement about unconditional worth will immediately change feelings. Do not frame grief, trauma reactions, disability or financial/social disadvantage as personal failure. The aim is a fair, useful relationship to oneself, not immunity from guilt or criticism.

Sources: Burns chapters 4, 8–9 and 13–14.
